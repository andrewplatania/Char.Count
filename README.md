# char.count

Count every character and line across your entire codebase

A fast minimal browser based tool for analyzing files or entire folders no install required

## Features

Upload individual files or entire folders
Counts total characters total lines files processed and files skipped
Option to skip unnecessary files like node_modules .git dist build and similar
Detects and ignores binary files
Sortable file breakdown by characters lines or filename
Clean terminal style interface

## Usage

Download or clone the repository
Open the HTML file in your browser 
Click Add Files to select individual files or Add Folder to scan a full directory
View stats and file breakdown within seconds

## How it works

Reads files directly in the browser using FileReader
Counts characters and line breaks for each file
Displays results in real time with sorting and filtering

## Configuration

Toggle Skip generated and dependency files to include or exclude ignored directories
Sort results using the dropdown menu
Clear results at any time with the clear button
